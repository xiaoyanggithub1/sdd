# 三多多的小站

写给三多多的专属小宇宙。奶油白与浅粉色，温柔浪漫，手机、平板、电脑都可以打开。

## 一键访问

合并到 `main` 后，打开仓库 **Settings → Pages**：

1. Source 选 **Deploy from a branch**
2. Branch 选 **main**，文件夹选 **/ (root)**
3. 保存大约一分钟后打开：

**https://xiaoyanggithub1.github.io/sdd/**

把这个链接发给三多多即可。手机浏览器也可以「添加到主屏幕」，像小应用一样点开。仓库需要是公开的，她才能不用登录直接打开。

本机也可以直接打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 8080
```

## 里面有什么

- **首页**：头像、问候、一封信，和今日一句
- **拍立得相册**：精致相框墙，点开可放大，也能继续加入新照片
- **纪念日**：倒数最近的日子，自己添加想记住的那天
- **留言板**：把想说的话放进信封
- **经期记录**：日历标记、周期预测，数据只存在这台设备上
- **音乐盒**：打开小站后播放汪小敏《最好的时光》完整版（约 4 分 12 秒）

留言、纪念日、经期和新照片都保存在浏览器本地，换设备需要重新写下。
